Reading a sine wave

Start at the centre line. The vertical distance from this line to a crest is the amplitude. Doubling it makes the wave taller while keeping the crests the same distance apart.

Now follow the curve from one crest to the next. The time between them is the period. Frequency counts how many of these cycles fit into one second. A 2 Hz wave takes half a second to complete each cycle.
